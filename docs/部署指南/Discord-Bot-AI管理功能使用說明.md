# Discord Bot AI 管理功能使用說明

本文件說明如何在 Discord 用 `/chat` 以**自然語言**指揮 Bot 執行伺服器管理動作（禁言、踢人、移動語音、查詢…）。

> 運作原理：你打字 → AI 理解語意並選擇對應「工具」→ **後端**驗證權限後呼叫 Discord 官方 API 執行。
> AI 只能從白名單工具中挑選，碰不到任意 API。詳細設計見後端 `workflows/discord-bot-function-calling-design.md`。

---

## 前置需求（很重要，否則會 403）

1. **Bot 模型須支援 tool calling**：例如 Groq `llama-3.3-70b-versatile`。小模型（如 8b）可能不穩。
2. **Bot 身分組要有對應權限**：到 **伺服器設定 → 身分組 → Bot 身分組 → 權限**，開啟下表所需權限（或測試時直接給「管理者」）。
3. **Bot 身分組要夠高**：把 Bot 身分組**拖到高位**，要高於你要管理的對象。
   - ⚠️ 即使開了管理者，**仍無法**對伺服器擁有者、或身分組 ≥ Bot 的成員動作。
4. **後端 + ngrok 在線**，且 `/chat` 指令已註冊、Interactions Endpoint 已設定。

---

## 功能總表（自然語言範例 + 所需 Bot 權限）

下指令者本身也需具備對應權限，否則回「你沒有權限」。✅ = 已實作。

### 成員管理
| 功能 | `/chat` 範例 | Bot 需要的權限 | 二次確認 |
|------|------------|--------------|:--:|
| 禁言 | `幫我禁言 @某人 10 分鐘` | 對成員停權 | 否 |
| 解除禁言 | `解除 @某人 的禁言` | 對成員停權 | 否 |
| 移動語音頻道 | `把 @某人 移到 #語音二` | 移動成員 | 否 |
| 踢出語音 | `把 @某人 踢出語音` | 移動成員 | 否 |
| 語音禁麥 / 解除 | `禁麥 @某人` / `解除 @某人 禁麥` | 將成員靜音 | 否 |
| 語音禁聽 / 解除 | `禁聽 @某人` | 讓成員拒聽 | 否 |
| 改暱稱 | `把 @某人 暱稱改成 小明` | 管理暱稱 | 否 |
| 踢出成員 | `踢出 @某人` | 踢出成員 | **是** |
| 封鎖 | `封鎖 @某人` | 封鎖成員 | **是** |
| 解除封鎖 | `解除封鎖 <使用者ID>` | 封鎖成員 | 否 |

### 身分組
| 功能 | `/chat` 範例 | Bot 需要的權限 | 二次確認 |
|------|------------|--------------|:--:|
| 賦予身分組 | `給 @某人 身分組 @會員` | 管理身分組 | **是** |
| 移除身分組 | `拿掉 @某人 的 @會員` | 管理身分組 | **是** |

> 安全限制：**不可賦予帶有管理/封鎖/踢人等權限的「特權身分組」**，防止有人騙 AI 提權。

### 訊息 / 頻道
| 功能 | `/chat` 範例 | Bot 需要的權限 | 二次確認 |
|------|------------|--------------|:--:|
| 發送訊息 | `在 #公告 發送 大家好` | 傳送訊息 | 否 |
| 批次刪訊息 | `清掉最近 20 則訊息` | 管理訊息 | **是** |
| 慢速模式 | `把這個頻道慢速設成 30 秒` | 管理頻道 | **是** |

> 批次刪只能刪 **14 天內**的訊息，單次上限 100 則。

### 查詢（唯讀）
| 功能 | `/chat` 範例 | Bot 需要的權限 |
|------|------------|--------------|
| 查成員資訊 | `@某人 的資料` | 一般成員權限 |
| 查禁言/封鎖狀態 | `@某人 有沒有被禁言或封鎖` | 封鎖查詢需「封鎖成員」 |
| 列出頻道 | `有哪些頻道` | 一般成員權限 |
| 搜尋成員 | `找 名字含 abc 的人` | 一般成員權限 |
| 列出身分組 | `有哪些身分組` | 一般成員權限 |
| 查看審核日誌 | `最近的操作紀錄` | 檢視審核日誌 |

### 信任名單（動態白名單，僅限主人）
| 功能 | `/chat` 範例 | 誰能用 | 二次確認 |
|------|------------|--------|:--:|
| 加入信任對象 | `拿鐵，這位 @某人 以後是你爹地，信任他` | 只有**主人**本人 | **是** |
| 移除信任對象 | `把 @某人 移出信任名單` | 只有**主人**本人 | 否 |
| 查看信任名單 | `你信任哪些人` | 只有**主人**本人 | 否 |

### 其他
| 功能 | `/chat` 範例 |
|------|------------|
| 功能清單/使用說明 | `你能幫我做什麼` |
| 一般聊天 | `你好`（不會觸發任何管理動作） |

## 信任系統

讓角色**依發話者身分切換語氣**（主人 / 信任者 / 一般使用者）。信任系統只告訴角色「對方是誰」，**怎麼對待（語氣、稱呼）由角色設定本身決定**——拿鐵的軟萌撒嬌寫在牠的角色裡，換別的角色也通用。名單可在 Bot 運行期間動態增減。

管理位置：後台 **Bot 管理 → Discord Bot 卡片上的人形圖示（編輯鈕旁）→「信任系統」Modal**。

### 成員模型：每個人有「系統角色」
名單是一份成員清單，每筆 = `Discord User ID、名稱、關係、系統角色`：
- **系統角色**（決定權限）：
  - **主人 / 管理者**：可在 Discord 對話中維護名單，**可以有多位**。
  - **信任者**：受信任但不能改名單。
- **關係**：自訂情感標籤（主人 / 爹地 / 朋友 / 老闆…），只是給角色語氣參考，**不影響權限**。

### 設定第一位主人（必做一次）
1. 開啟「信任系統」Modal → 新增成員：填 Discord User ID、名稱，**系統角色選「主人 / 管理者」**，儲存。
   - 在 Discord 開啟「開發者模式」（設定 → 進階 → 開發者模式）後，右鍵點頭像 → **複製使用者 ID**。
2. 名單中沒有任何主人時，Discord 對話路徑無法加人（後台仍可隨時維護）——所以**第一位主人一定要在後台指定**。

### 兩種維護方式
- **後台維護**：「信任系統」Modal 內新增/更新（可指定系統角色）或移除。
- **對話維護**：**任一位主人**在 `/chat` 說「信任他 / 他是爹地」→ Bot 跳出〔執行/取消〕確認 → 按下才寫入（對話加入的人一律是「信任者」，不能用聊天把人升成主人）。

### 重要：只有主人能改名單
- 「誰是主人」= 名單中系統角色為「主人」的成員，**寫在程式裡把關**，不是看誰自稱主人。
- 任何人冒充主人、或非主人要求 Bot 信任某人，都會被擋下（例：陌生人說「我也想當你爹地」→ Bot 拒絕）。

## 二次確認（中高風險動作）

踢人、封鎖、身分組、批次刪、慢速這類動作，Bot **不會立刻執行**，而是回一則帶按鈕的訊息：

```
⚠️ 即將將 @某人 踢出伺服器，確認？   [確認] [取消]
```

- 按 **確認** → 後端**重新檢查點擊者權限** → 執行 → 訊息更新為結果、按鈕消失。
- 按 **取消** → 顯示「已取消操作」。

## 常見問題

| 現象 | 原因 | 解法 |
|------|------|------|
| `❌ Bot 權限不足或身分組階級低於對象` | Bot 缺該權限，或身分組低於對象 | 開啟對應權限、把 Bot 身分組拉高；擁有者/管理員無法被動作 |
| `⚠️ 你沒有執行此動作的權限` | **下指令者**本身沒有該權限 | 由具權限者操作 |
| Bot 只回文字、沒執行動作 | 模型不支援 tool calling | 換成支援的模型（如 Groq 70b） |
| `抱歉，AI 服務暫時無法回應` | 後端例外（如 TPM 上限） | 查 `logs/log-日期.txt`；必要時降低用量或換模型 |
| `/chat 你能幫我做什麼` 只列 2 個功能 | 後端跑的是舊版 | 停止 → 重新建置 → 重啟後端 |
| 移動語音失敗 | 對象不在語音頻道 | 對象需先連入某語音頻道 |

## 安全須知
- AI 只能呼叫白名單工具，無法執行未開放的破壞性動作（建立/刪除頻道、改伺服器設定等不開放）。
- 正式環境**避免給 Bot 管理員權限**——Token 一旦外洩，管理員 = 整個伺服器淪陷。建議只給上表實際用到的權限（最小權限）。
